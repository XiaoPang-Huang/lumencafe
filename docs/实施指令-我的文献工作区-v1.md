## 轮①：用户世界隔离 + 我的文献页骨架 + 添加/删除

**后端**：
1. Alembic 0011（只增）：papers + `user_id`(int, 索引)（存量行回填：按 paper_users 最早收藏人/默认 admin，回报写明口径）；新表 `paper_library`（id/user_id/paper_id/added_via(crawl|import)/created_at，unique(user_id,paper_id)）；`papers_crawl_runs.progress` JSONB 可空
2. 抓取按人入库：papers_crawl 的 upsert/去重**限定同 user 内**（dedupe key 加 user 维度）；digest/daily/favorites/annotations/content/parse 全部查询加 user 过滤（含 wentt 隔离测试）
3. `POST /papers/{id}/library`（加入我的文献，幂等）/ `DELETE /papers/{id}/library`（删除=级联本人 papers 行+批注+COS 四件+收藏/库关联）/ `GET /library`（我的文献列表：元数据+parse_status+annotations_count）
4. 导入占位：papers.origin(crawl|import)+owner 语义用 user_id 承载（P23）

**前端**：
5. 一级页 #/library：顶部导航注册+⌘K 直达；三栏（左列表/中阅读器复用/右批注）；「解析中」tab 占位（轮②填）
6. 详情面板/卡片操作行加「＋ 我的文献」（已加入态「✓ 已在库」）；**详情笔记区改纯只读**+「到我的文献中阅读与批注」引导；左导航「我的笔记」改名「我的文献」指向 #/library
7. 删除确认弹窗：红字「删除后该文献及其相关笔记会一并删除，且不可恢复」+ 「确认删除」

**测试**：两用户隔离（A 抓的 B 看不到/删 A 不动 B）；library CRUD+幂等；级联删（papers/notes/COS spy/收藏行全清）；回归全绿。commit `feat(论文域): 用户世界隔离+我的文献一级页+添加删除级联`。

## 轮②：导入 + 解析入口收紧 + 双进度条

1. **导入弹窗**（#/library 顶部「导入文献」）：① PDF 文件上传（前端直读 bytes→后端，≤30MB，落 COS pdfs/ + 自动进我的文献+解析状态机）② arXiv ID / DOI 粘贴（后端拉元数据——arXiv API/Crossref，下载 OA 全文；**失败→该条目 failed 态+原因可见+通知 toast**）；`POST /library/import`
2. **解析入口收紧**：详情面板「收藏并解析」改为「＋我的文献」（解析只在 #/library 发起）；`POST /papers/{id}/collect-parse` 校验论文在本人 library 内（否则 403）
3. **解析进度**：#/library「解析中」tab=全部非 done 任务列表，每条五段阶段条（下载→上传→排队→解析中→完成）；状态从 parse_status+新增 parse_phase 字段驱动（轮询）
4. **检索进度条**：crawl-now 期间后端写 runs.progress（phase: fetching|translating|done + per_source 计数+当前关键词）；`GET /papers/crawl-now/status` 轮询；前端按钮变进度条弹层（阶段式，轮询到完成自动刷新 digest）

**测试**：导入两路（PDF 落 COS 断言/arXiv 元数据+下载失败通知断言）；解析 403 非库内；progress 写入与轮询；回归全绿。commit `feat(论文域): 文献导入(PDF/arXiv/DOI)+解析收紧+检索与解析双进度条`。

## 轮③：中英对照翻译

1. `POST /papers/{id}/translate`（仅库内、parse done）：读 parsed/{id}/full.md→按 content_list block 分批（每批≤15 段）走网关 chat_once（app_key=`papers_translate`，系统提示词内置：学术翻译、保留术语、严格 JSON 返回 {block_id: zh}）；结果合并写 `parsed/{id}/translation.json`；翻译状态字段 translate_status(none|running|done|failed) 入 papers
2. 阅读器：有 translation.json 时英文段落下渲染中文段（上下对照样式）；「翻译」按钮（未翻译时）/「重新翻译」；失败显示原因可重试
3. #/library 设置小项：「导入后自动翻译」开关（papers_prefs，默认关；开启则解析 done 自动触发）

**测试**：翻译 mock 网关（分批断言/JSON 解析失败重试）；translation.json 落 COS 断言；自动翻译开关联动；回归全绿。commit `feat(论文域): MinerU段落级中英对照翻译（按钮触发+缓存）`。
