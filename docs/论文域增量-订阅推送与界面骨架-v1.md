## 本批实施范围（P1-P7）

1. **后端**：
   - Source Provider 抽象（契约冻结，学 skillhub.py 模式；先实现 arXiv + OpenAlex + S2 + DOAJ 四个，PubMed 收编为 provider 之一）+ papers_crawl 改造为按用户订阅源聚合
   - `subscribe_sources` 入 user_settings（或独立字段，开工时定）；digest 聚合：按用户关键词打分（沿用现有打标逻辑泛化），高相关阈值
   - `POST /papers/crawl-now`（手动立即检索，内部令牌或登录用户触发，幂等）+ digest 查询接口（今日命中列表 + 高相关标记 + last_run 时间）
   - AI 生成关键词：`POST /papers/suggest-keywords`（一句话 → 关键词组，走网关 app_key=papers_config）
   - Hatchet：compose +1 引擎容器（复用现有 PG 独立库名），每日定时 workflow 调抓取；管理页可链 /admin/hatchet 控制台（D7/D8 既定形态）
2. **前端**：论文页按 P7 骨架重排 + 订阅设置弹窗 + 立即检索 + digest 板块
3. **明确不做**：ntfy、谷歌/必应学术、下载、预览、批注笔记、问答（后续批次）
