# 04 · 其他核心功能模块

## 1. 首页（Home）

### 功能描述与布局（证据：`pages/home/index.tsx`、`banner.tsx`、`datasets.tsx`、`applications.tsx`）

不是 Bento 仪表盘，而是**纵向流式分区**：超大欢迎 Banner → 知识库区 → 应用区。

- **Banner**：「Welcome」普通字重 + 「RAGFlow」渐变字（`bg-gradient-to-l from-[#40EBE3] to-[#4A51FF]`）。
- **知识库区**：横向单行滚动容器，最多 6 张 DatasetCard + 末尾固定一张「SeeAll」卡（文案 + ChevronRight）。
- **应用区**：Segmented 分段控件在「对话 / 搜索 / Agent / 记忆」间切换（纯前端切换，不跳路由），右侧联动渲染对应卡片列表。
- 无数据指标仪表盘——首页定位是「最近使用 + 入口聚合」，每类资源只露前 N 条，用 SeeAll 卡收束。

### 设计要点

首页每类资源只取 `slice(0, 6)`/`slice(0, 10)`，把「浏览全部」收敛为一张卡；空态卡点击即创建并深链 `?isCreate=true` 自动弹创建框。

## 2. 知识库（Dataset）

### 2.1 列表页（证据：`pages/datasets/index.tsx`、`dataset-card.tsx`）

标准列表骨架。卡片描述字段被复用为轻指标：`{document_count} files`；右上角下拉提供重命名/复制/权限管理。

### 2.2 创建对话框（证据：`pages/datasets/dataset-creating-dialog.tsx`）

Dialog（`sm:max-w-[425px]`）内嵌 react-hook-form + zod，`superRefine` 条件校验：`parse_type` 选 BuiltIn 必须选解析器、选 Pipeline 必须选 pipeline——**条件字段互斥必填**的成熟范式。解析器选择是统一的树形组件（内置解析器与 Pipeline 版本同树），提交时 `omit` 无关字段。细节：监听 Enter 提交且排除输入法合成状态。

### 2.3 详情页（证据：`pages/dataset/`）

次级侧栏五页签：

**A. 文件页签**——最复杂的页面：

- 解析状态列是一个完整状态机（证据：`dataset/dataset/parsing-status-cell.tsx`）：
  - 状态：UNSTART / RUNNING / QUEUED / SCHEDULE / CANCEL / DONE / FAIL → 图标映射 + `data-state` 测试定位属性。
  - 运行中：行内细进度条 + 百分比 + 日志问号图标 + 取消按钮。
  - **取消中（STOPPING）**：原行加半透明遮罩 + 转圈（dimmed + scrim 模式）。
  - 排队中：时钟图标 "Queued"。
  - 完成/失败：重解析图标 + `ParsingCard` 悬浮卡（耗时、`[ERROR]` 正则红色高亮）。
  - 重解析保护：已有 chunk 时弹确认；解析器被删时警告阻止。
- 批量操作：运行 / 取消 / 启用 / 禁用 / 批量元数据 / 删除；解析前做「解析器能力缺口校验」（视频等无可用解析器时区分「全部受阻」「部分可解析」两种文案）。

**B. 检索测试页签**（证据：`dataset/testing/index.tsx`）

经典左右双栏对照（`grid-cols-2 divide-x-0.5`）：左测试设置表单、右结果；结果按文件聚合筛选，每个 chunk 卡并排显示三种相似度分数（Hybrid / Term / Vector）。

**C. 概览/日志**：解析过程日志弹窗。

**D. 配置页签**（证据：`dataset/setting/index.tsx`）：单页大表单，schema 动态构建；变更解析器时询问是否应用到存量文件。

**E. 知识图谱**：ForceGraph 全屏渲染 + 右上角删除按钮。

## 3. 文件管理（Files）

证据：`pages/files/index.tsx`、`file-breadcrumb.tsx`、`hooks/`

- **无目录树，只有面包屑**：根目录标题是文案 "Files"，进入子文件夹切换为 Breadcrumb（末级不可点）。面包屑数据由 URL 派生。
- 主按钮 "AddFile" 是 Dropdown（上传文件 / 新建文件夹，带分隔线）。
- 批量操作：移动 / 添加到知识库 / 删除（复用 BulkOperateBar）。
- **容错设计**：当前文件夹被移动/删除后自动跳回根目录而不是报错。
- 通用上传组件 `components/file-uploader.tsx`：react-dropzone，文件卡 = 缩略图（图片有 preview）+ 名称 tooltip + 大小 + 进度 + 删除。

## 4. Agent（画布工作流）

### 4.1 列表页与模板画廊（证据：`pages/agents/index.tsx`、`agent-templates.tsx`）

- 列表页筛选栏左侧被替换为**胶囊页签组**（Compilation / Pipeline / Workflow 三类画布，URL 参数驱动）。
- 创建入口是聚合菜单：新建空白 / 从模板创建 / 导入 JSON DSL / 上传 agent 文件。
- 模板画廊：左侧主题侧栏 + 右侧网格；模板卡是**hover 显形模式**——本体头像+标题+描述，hover 叠加黑色渐变色罩 + 底部浮现 "Use this template" 按钮。
- 模板创建的巧妙处：表单先收集名称/模型/知识库，前端把知识库与模型**注入模板 DSL**（`bindUnboundRetrieval`/`bindUnboundModel`）后一次性创建并跳画布。

### 4.2 画布（证据：`pages/agent/canvas/index.tsx`）

确认是 **React Flow（@xyflow/react）**：

- 注册约 20 种节点组件（begin/agent/retrieval/tool/categorize/switch/iteration/loop/note 等），自定义 ButtonEdge（边上带删除按钮），只读模式整体换 ReadonlyEdge。
- 核心交互：从节点拖连线 → 松手处弹出算子选择下拉 → 生成占位节点；点击空白收起配置面板。
- 侧开面板体系：节点点击 → 右侧 FormSheet（约 60 种算子表单）；顶部操作触发 ChatSheet（调试对话）/ RunSheet / LogSheet。
- 图状态 zustand `useGraphStore`。

### 4.3 运行/探索界面（证据：`pages/agent/explore/index.tsx`）

固定左右布局：296px 会话列表 + 右侧 SessionChat，sessionId 在 URL 参数中（可分享/刷新保持）——与对话页同构。

## 5. 记忆（Memory）

证据：`pages/memories/index.tsx`、`pages/memory/`

- 列表页标准骨架；创建/编辑共用 `AddOrEditModal`。
- 详情页与知识库同构（次级侧栏两页签：Messages / Configuration）。
- 记忆消息流**不是聊天气泡而是表格**：搜索 + 筛选 + 分页展示被抽取的消息记录（来源会话、内容、抽取的记忆），支撑检索与删除管理。

## 6. 搜索（Search）

### 6.1 应用列表（证据：`pages/next-searches/index.tsx`）

标准卡片网格；创建仅收集名称，创建后进入详情配置。

### 6.2 搜索详情/结果页（证据：`pages/next-search/index.tsx`、`search-view.tsx`、`retrieval-documents/index.tsx`）

**三态单页应用**：

```
SearchHome（首页大搜索框）→ SearchingPage（结果流）→ SearchSetting（右侧设置面板）
```

- 状态切换配 `animate-fade-in-down/up` 过渡；设置面板右侧悬浮齿轮开合（440px），首次进入未配置 LLM 时强制打开。
- 结果页顶部固定 Logo（点击退回首页态）+ 大号自适应圆角搜索框（单行 `rounded-full`，多行自动变 `rounded-3xl`）。
- **引用按文档聚合**：「已选 x/总数 文件」Popover 多选器，把命中的 chunk 按文档聚合，Command 面板内勾选过滤引用来源，**关闭时才一次性提交重新检索**（draft/commit 双缓冲，弹窗内点击不触发搜索）。
- 引用回溯：调 `useGetChunkHighlights` 在原文件（PDF）中高亮定位引用位置。
- 附加视图：思维导图 Sheet、相关追问、Markdown 渲染。

## 7. 技能（Skills）

证据：`pages/skills/index.tsx`（1216 行单页两级视图）

- **技能空间本质上是文件系统目录** `root/skills/{space}`：空间卡片的大小/创建时间由文件管理器 API 实时聚合；上传技能 = 向文件夹写文件 + 触发向量索引；面包屑可直接跳文件管理器对应目录——数据层完全打通。
- 两级列表：Space 列表（网格/列表 Segmented 切换 + 批量删除）；Space 内技能列表（搜索、排序、网格/列表、索引配置、刷新、添加）。
- 技能搜索是**服务端语义检索**与本地列表融合（结果用 id/name 双 Map 与本地合并补全字段）。
- 技能详情是 Drawer：版本列表 + 文件树 + markdown/code viewer。
- 空态按「已搜索无结果 / 有搜索词 / 全空」三态分别给文案，全空时内嵌添加入口。

## 8. 通用组件模式汇总（跨模块复用的基础设施）

| 模式 | 说明 | 证据 |
|---|---|---|
| 统一列表页骨架 | 筛选栏+响应式网格+分页+空态，7 页完全同构 | `components/list-filter-bar`、`card-container`、`empty/empty.tsx` |
| 卡片即协议 | HomeCard 一个组件承载 5 类资源卡片 | `components/home-card.tsx` |
| 危险操作约定 | 批量条 `id='delete'` 自动包确认弹窗 | `components/bulk-operate-bar.tsx` |
| 三级侧栏联动 | 主导航折叠 ↔ 详情页次级侧栏折叠联动 | `pages/dataset/index.tsx` |
| 详情页左侧页签 | 替代顶部 Tabs，沉浸操作 | `pages/dataset/sidebar`、`pages/memory/sidebar` |
| 解析状态机 UI | 行内进度+取消+停止遮罩+排队时钟+ERROR 高亮日志卡 | `pages/dataset/dataset/parsing-status-cell.tsx` |
| 引用按文档聚合 | chunk→doc 聚合多选，关闭才提交（draft/commit 双缓冲） | `pages/next-search/retrieval-documents` |
| 条件字段表单 | zod superRefine 互斥必填 | `pages/datasets/dataset-creating-dialog.tsx` |
| 模板注入式创建 | 模板 DSL 前端绑定资源后一次性创建 | `pages/agents/agent-templates.tsx` |
| 网格/列表双视图 | Segmented 切换 + 批量操作 | `pages/skills/index.tsx` |
| 数据与文件系统打通 | skill space = 文件目录 + 向量索引 | `pages/skills/index.tsx` |
