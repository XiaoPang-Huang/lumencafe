- 根因（复验挖出的真 bug）：`usage/summary` 默认时间窗 `end=datetime.now(UTC)`，而 `llm_call_logs.created_at` 由 PG `now()` 落库——库钟领先应用时钟亚秒级时，刚写入的日志被 `created_at < end` 误排除（偶现）。修复：默认 end 加 5 分钟前瞻缓冲（`fix(底座)` 单独 commit）。
- 修复后：test_routing 连跑 3 遍全绿、全量 124 passed、ruff 过；api 容器已重建 healthy，Caddy 反代链路验证通。
