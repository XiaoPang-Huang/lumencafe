- **共 34 个源，7 个分类**：综合索引（8）、生物医学（4）、理工（4）、社科人文（5）、中文国内（6）、开放期刊/预印本（4）、商业收费（3+跨类收费源若干）

## 7. 推荐接入优先级

技术前提：Python 后端 + httpx + tenacity、两人轻量自托管、无商业压力。选型三要素：**免费可得性 > API 工程质量 > 覆盖增量**。

### 一期（已接入，仅需注意政策变化）
PubMed、arXiv、OpenAlex、Semantic Scholar、DOAJ
- ⚠️ OpenAlex：需引导用户配免费 key（$1/天额度足够个人使用），否则无法 cursor 深分页
- ⚠️ Crossref 速率 2025-12 起收紧，但不在一期

### 二期推荐 Top 5（按优先级）

| 排名 | 源 | 理由 | 成本 | 预估工作量 |
|---|---|---|---|---|
| 1 | **Crossref** | DOI 元数据权威底座；免费无 key；补一期所有源的 DOI 规范化、引用数交叉验证 | 零 | 小（标准 REST） |
| 2 | **Europe PMC** | PubMed 超集+OA 全文+预印本（含 bioRxiv/medRxiv/SSRN 索引），免费无 key、10 req/s 大方；一次请求直返记录 | 零 | 小 |
| 3 | **CORE** | 5700 万 OA 全文直链，是"拿到 PDF"的关键补链源；免费额度对自托管够用 | 零 | 中（返回体大需裁剪字段） |
| 4 | **AMiner** | 中文+英文学术 API 质量最高的国内源，被引档位+双语标题，按次计费极便宜（0.01 元/次），覆盖国内源空白 | ≈零 | 小 |
| 5 | **bioRxiv/medRxiv** | 预印本→正式发表链路（pubs 端点）是差异化能力；免费无 key；配合 Europe PMC 的 SRC:"PPR" 关键词检索弥补其无检索缺陷 | 零 | 小 |

**二期次优候选**：IEEE Xplore（免费 key 仅 200 次/天，工科会议不可替代但额度小）、dblp（CS venue 枚举权威，免费无 key）、Springer Nature Meta API（免费 500 次/天，元数据+OA 全文）、BASE（OA 覆盖广但接口老旧）。

### 三期/按需
- **用户配 key 即启用**（订阅制，UI 勾选+key 管理即可）：Scopus、Web of Science（Starter 免费档）、ScienceDirect、IEEE Xplore 提额、Embase、Cochrane
- **只做链接跳转源**（无 API）：SSRN、SPIE/Optica、百度学术、ncpssd、维普
- **题录文件导入形态**：CNKI、万方（有 API 但订阅）、维普、PsycINFO、JSTOR DfR —— 用户在各站导出 Refworks/EndNote/CSV，系统解析入库

## 8. 自定义源模板（用户自定义添加）

用户场景：指定 arXiv 分类持续跟踪、限定某期刊、挂某个 OAI-PMH 端点（如 PhilArchive）、机构库收割（如自家大学 repository）。

### 8.1 建议支持的自定义形态

| 形态 | 类型标识 | 说明 | 需要的限定条件 | 对应 key 表服务名 |
|---|---|---|---|---|
| OAI-PMH 端点 | `oai_pmh` | 任意支持 OAI-PMH 的仓库/期刊/档案（arXiv、PhilArchive、RePEc、机构库、DOAJ dump 等） | endpoint URL、metadataPrefix（oai_dc/arXiv/JATS）、set（可选，如 arXiv `cs.LG`）、from/until 增量窗口 | 无（OAI-PMH 通常免 key；个别需注册的进 key 表） |
| REST API 模板 | `rest_template` | 预置参数化模板：用户填 base_url + 查询参数映射 | base_url、检索参数名映射（q/title/author/year）、分页方式（page/cursor/offset）、响应 JSON 字段映射（title/abstract/authors/doi/url） | 可选（`CUSTOM_API_KEY` 引用 key 表） |
| arXiv 分类限定源 | `arxiv_category` | 一期 arXiv 的实例化自定义：跟踪某分类/作者/关键词组合 | 分类列表（如 cs.AI, cs.LG）、查询式、更新频率 | 无 |
| 期刊/会议限定源 | `journal_watch` | 限定 ISSN/期刊名，走 Crossref/OpenAlex filter 实现 | ISSN 或期刊名列表、日期窗口 | 可选（OpenAlex key 引用） |
| 题录文件导入 | `file_import` | CNKI/万方/维普/PsycINFO/JSTOR 等无 API 源 | 文件上传（Refworks/EndNote/CSV/RIS/BibTeX）、来源标注 | 无 |
| RSS/Atom 监控 | `rss` | 期刊 TOCs、预印本新品推送 | feed URL | 无 |

### 8.2 自定义源需要提供的信息（数据模型建议）

```yaml
custom_source:
  name: string              # 必填，展示名（如 "arXiv cs.LG 跟踪"）
  type: enum                # 必填，oai_pmh / rest_template / arxiv_category /
                             #       journal_watch / file_import / rss
  enabled: bool
  # —— 按类型的限定条件 ——
  endpoint_url: string      # oai_pmh / rest_template / rss 必填
  metadata_prefix: string   # oai_pmh 必填（oai_dc / arXiv / JATS）
  oai_set: string           # oai_pmh 可选（如 cs、cs:cs:AI）
  query: string             # arxiv_category / rest_template / journal_watch 必填
  filters:                  # journal_watch 等
    issn: [string]
    year_from: int
    year_to: int
  field_mapping:            # rest_template 必填：JSON 字段映射
    title: string
    abstract: string
    authors: string
    doi: string
    url: string
    published: string
  pagination:               # rest_template 可选
    mode: enum              # page / cursor / offset
    page_size: int
  refresh_interval: string  # 必填，如 "6h" / "1d"（增量 from/until 窗口）
  # —— key 关联 ——
  key_service: string       # 可选，指向 key 表的服务名（openalex / ieee / aminer / custom:<name>）
  # —— 展示与归属 ——
  category: enum            # 建议沿用主分类，允许用户自定义标签
  notes: string             # 备注
```

### 8.3 注意事项
- **OAI-PMH 速率礼仪**：3-20 秒间隔 + tenacity 重试，尊重 resumptionToken
- **field_mapping 校验**：保存自定义源时做一次试检索 + 映射校验，字段缺失给警告不阻断
- **key 表设计**：主键 = 服务名（如 `openalex`、`ieee_xplore`、`aminer`、`scopus`），自定义源用 `custom:<source_name>` 隔离，支持"一个服务多个 key"（备用轮换）
- **file_import 去重**：以 DOI 优先、标题+作者+年份模糊匹配兜底，与 API 源结果合并去重
