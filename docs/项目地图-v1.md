## 1. 顶层总览

```

├── deploy/            生产覆盖层（prod：IP/前端挂载；另存域名模式备用件）
├── docker-compose.yml 全栈编排（db / api / backup / hatchet / caddy）
├── LICENSE            MIT（开源就绪）

├── docs/              📄 产品契约与协作规范（本文所在）
├── backend/           ⚙️ FastAPI 后端（批次 1 地基已建）
```

## 3. prototype/v2/ —— 前端原型

```
prototype/v2/
├── index.html            外壳 + 全局弹层 + ?v= 版本号（改 JS/CSS 后 bump）
└── assets/
    ├── js/api.js         API 客户端层（token 存取 + fetch/SSE 封装 + 401 跳登录）
    ├── js/app.js         路由 + 页面模板 + ⌘K 面板 + 全部事件委托（P8 批注阅读器：
    │                     左原文段落流/右批注栏、选中弹钮、互链选择器、导出 Markdown；
    │                     轮① P22 起支持挂载态 openReader(pid, flashAid, mount)，
    │                     #/library 我的文献一级页三栏复用：左列表/中阅读器/右批注栏；
    │                     轮② P25/P26/P28：导入弹窗（PDF FileReader→base64 /
    │                     arXiv·DOI 粘贴，失败 toast）、解析中 tab 五段阶段条
    │                     （parse_phase 轮询）、立即检索进度弹层
    │                     （crawl-now/status 1.5s 轮询）、详情面板解析状态只读
    │                     （解析入口收紧为仅库内发起）；
    │                     轮③ P27：阅读器中英对照（英文 text 块下渲染 muted 小字
    │                     中文段，同 block_id 锚点）、「翻译/重新翻译」按钮 +
    │                     翻译中流式态 + 2s 轮询、#/library 设置小项「导入/解析后
    │                     自动翻译」开关（papers_prefs.auto_translate））
    ├── js/data.js        演示数据（工作台/应用中心/平台管理页仍用；对话/记账已联调真实 API）
    ├── js/icons.js       data-ic 图标注入
    ├── css/main.css      全部样式
    ├── icons/            SVG 源文件 + build-icons.js
    └── fonts/            本地字体
```

本地联调：`prototype/` 起静态服务（`python -m http.server 4311`）→
`http://localhost:4311/v2/`，后端 CORS 需含 `http://localhost:4311`（root .env 的 LUMEN_CORS_ORIGINS）。
