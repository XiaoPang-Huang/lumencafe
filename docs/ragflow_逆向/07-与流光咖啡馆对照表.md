## 5. PDF 文档展示与阅读对照（深挖补全）

> 这是 RAGFlow 真正的技术深水区：**chunk 坐标由后端解析时产出，前端只做渲染映射**。

### 5.1 渲染技术栈

| 项 | RAGFlow | 流光现状 |
|---|---|---|
| PDF 引擎 | pdfjs-dist（本地 worker `/pdfjs-dist/pdf.worker.min.js` + cMap + standard_fonts，`document-preview/pdf-preview.tsx:102-107`） | 待核实（我们 reader 实现方式） |
| 高亮库 | **react-pdf-highlighter**（`pdf-preview.tsx:18-25`）：渲染层叠高亮框、滚动定位、Area 选择 | ❌ 我们无坐标级高亮 |
| 后端坐标 | chunk 带 `positions` 字段：`[页码, x1, x2, y1, y2]` 数组（`utils/document-util.ts:24-58` `buildChunkHighlights`），解析器（MinerU 等）产出 | ❌ 我们的 MinerU 在线 API 是否返回坐标？**待核实——这是论文域对齐的关键问题** |
| 缩放适配 | 取第 1 页 viewport 原始宽高存 state → 高亮框按显示宽度等比缩放（`use-document-request.ts:821-840`） | — |

### 5.6 小结：论文域可借鉴清单

1. **坐标高亮链路**：解析器产出坐标 → 前端矩形映射 → 自动滚动定位。前提：MinerU 在线 API 返回块坐标（待核实）。
2. **chunk 级管理**：分页 + 关键词搜索 + 可用性开关，比我们「整篇问答带出处」细一档。
3. **查看器格式分派模式**：一个入口按扩展名路由预览器，将来文件管理可复用。
4. 不用学：无批注、无连续分块阅读——这两块我们已有/可自主设计。

## 9. 落地优先级建议

1. **论文模块对齐 Dataset 骨架**——收益最大：列表四段式 + 解析状态机五态 UI + 详情次级侧栏 +（若 MinerU 返回坐标）引用定位高亮。

5. **新模块直接复用同构骨架**——应用中心 / Skill 中心 / Key 管理。
