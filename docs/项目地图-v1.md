# 流光咖啡馆项目地图 v1

> 目的：10 秒内定位"要改的东西在哪个目录"。
> 交互式可搜索版本：[项目地图.html](项目地图.html)（浏览器打开即可）。
> 目录结构变化时记得同步更新本文 + HTML 版。

## 1. 顶层总览

```
lumencafe/
├── AGENTS.md          设计强制规则 + 工程约定（最高优先级）
├── README.md          快速开始、目录说明
├── Caddyfile(.dev)    生产 / 开发反代配置
├── docker-compose.yml 全栈编排（api / db / caddy / n8n）
│
├── docs/              📄 产品契约与协作规范（本文所在）
├── backend/           ⚙️ FastAPI 后端（批次 1 地基已建）
├── prototype/v2/      🎨 前端交互原型（拍板用，纯静态）
├── n8n-zh/            🤖 n8n 中文界面包（不入库，按 README 下载）
├── old/               🗄️ 旧版后端（仅本地参考，不入库）
└── .workbuddy/        🧠 AI 协作记忆（日志 + 项目长期笔记，不入库）
```

## 2. backend/ —— 后端

```
backend/
├── app/
│   ├── main.py           FastAPI 入口 + /health（挂新路由来这里）
│   ├── config.py         全部配置（LUMEN_ 前缀环境变量 → settings）
│   ├── db.py             引擎 + 会话 + ORM 基类 Base
│   ├── logging_conf.py   日志
│   ├── security.py       bcrypt 密码哈希 + JWT 签发/校验
│   ├── deps.py           get_current_user / require_permission / internal_token_guard
│   ├── models/           ORM 十六表（架构设计 §3；__init__ 汇总供 Alembic）
│   ├── schemas/          请求/响应模型（auth / admin / me / llm / money / apps；按 PRD §4）
│   ├── services/         业务服务层（llm_gateway / route_service / money_service /
│   │                     rbac_service / seed / rate_limit / papers_crawl）
│   └── routers/          批次 1 全部已建：auth / admin_users / admin_models /
│                         me / money / apps / internal / gateway / chat（T05 收官）
├── tests/                pytest（独立库 lumencafe_test：conftest 建库+迁移+种子）
│                         7 个测试模块 56 用例全绿
├── alembic/
│   ├── env.py            迁移环境
│   └── versions/         迁移文件（只新增不改旧；0001 = 批次1全量 16 表）
├── requirements.txt      运行时依赖
├── requirements-dev.txt  开发依赖（ruff / pytest）
├── pyproject.toml        ruff 配置（FastAPI Depends 视为不可变调用）
├── .env.example          环境变量完整清单（改配置先看这里）
├── Dockerfile            api 镜像（启动自动跑 alembic upgrade head）
└── .venv/                本地虚拟环境（不入库）
```

## 3. prototype/v2/ —— 前端原型

```
prototype/v2/
├── index.html            外壳 + 全局弹层 + ?v= 版本号（改 JS/CSS 后 bump）
└── assets/
    ├── js/app.js         路由 + 页面模板 + ⌘K 命令面板 + 全部事件委托
    ├── js/data.js        演示数据（金额一律「分」）
    ├── js/icons.js       data-ic 图标注入
    ├── css/main.css      全部样式
    ├── icons/            SVG 源文件 + build-icons.js
    └── fonts/            Manrope woff2（本地）
```

本地预览：在 `prototype/` 目录起任意静态服务，如
`python -m http.server 4311` → 打开 `http://localhost:4311/v2/`。
