## 2. 总体架构

```
浏览器（手机/电脑/PWA）
   │ HTTPS
Caddy ── 静态托管 React 构建产物 │ 反代 /api │ SSE 不缓冲
   │
FastAPI ──┬─ 平台层：账号/RBAC、应用注册表、模型管理
          ├─ 应用 API：对话 记账 文献
          ├─ AI 网关：对话 SSE / 解读 / 结构化解析（DeepSeek/Kimi/OpenAI 兼容端点）
          └─ 内部任务接口：文献抓取触发（n8n 调用，内部令牌鉴权）
   │
PostgreSQL（user_id 行级隔离）
   │
n8n（后装；仅用于文献抓取定时触发，不直连数据库）
```

技术栈：Vite + React + TS + shadcn/ui + Tailwind（一套代码手机/电脑自适应）。

## 3. 账号与权限（RBAC）

- 三件套分离：`users`（账号：用户名+密码 bcrypt）、`roles`（admin/member）、`permissions`（权限点，如 `app:chat`、`admin:users`、`admin:models`）+ `user_roles`、`role_permissions` 关联表；
- 后端用依赖注入做校验：`require_permission("admin:models")` 装饰器；
- v1 只设两个角色，表结构按可扩展设计（权限点驱动，不写死角色判断）；
- 登录 JWT 30 天过期，无 refresh token；忘记密码 = 管理员后台重置；
- 注册开关：环境变量 `REGISTRATION_OPEN=false`（默认关），实例部署者自行开启。

## 4. 模型管理（参考 Dify / LobeChat 的方案）

- **Provider 抽象**：一个 provider = 名称 + base_url + API Key + 类型（OpenAI 兼容即可覆盖 DeepSeek/Kimi/其他）；
- **模型配置**：每 provider 下挂模型清单，参数含 temperature / max_tokens / top_p；
- **应用级覆盖**：每个对话应用绑定（provider, 模型, 系统提示词, 参数覆盖），存 settings 式键值或独立表；
- **管理页**：仅 admin 可见；Key 存库（自部署威胁模型低），环境变量作初始默认值；
- 后端读取配置 → 调对应端点；对话接口完全配置驱动。

## 5. 应用清单

| # | 应用               | 模式  | 实现要点                                     |
| - | ---------------- | --- | ---------------------------------------- |
| 0 | 账号/权限/模型管理       | 平台层 | 见 §3 §4                                  |
| 0 | 应用面板（首页工作台+应用中心） | 平台层 | 应用注册表数据驱动                              |
| 1 | 对话（通用，app_id=chat） | 对话型 | ChatApp 组件 + SSE；绑定通用助手提示词，管理员可在模型管理页修改 |
| 1 | 记账               | 数据型 | 账目 CRUD + 自定义分类 + 月度统计/趋势 + AI 记一笔（request_id 幂等） |
| 2 | 文献推送/收藏/笔记/AI 解读 | 混合型 | 现有 CRUD + 解读按钮调 AI 接口；抓取由 n8n 定时触发内部接口     |

**对话通用件（关键设计）**：一个 `ChatApp` React 组件 + 一个 `POST /chat {app_id, messages}` SSE 接口。后端按 app_id 查提示词与模型配置。消息历史按 user + app 分表，保留轮数限制。

## 6. 数据、文件与备份

- 业务数据全部 PostgreSQL，user_id 行级隔离（现状已如此）；
- 文件先存服务器本地目录；COS 列为可选；
- 自动备份：本期不做；由部署侧手动 pg_dump / 云厂商快照兜底，后续批次再议；
- 开源前必须补 Alembic 迁移（替代 create_all）。

## 7. 自动化：n8n 定时触发（仅文献抓取）

- 后端**不做进程内定时任务模块**；
- n8n（后装，~0.3G）仅承担一个职责：每日固定时间（cron 在 n8n 工作流内配置）调用后端内部触发接口 `POST /internal/jobs/papers-crawl`（内部令牌鉴权，占位名以架构设计为准），执行一轮文献抓取；
- n8n 不直连数据库，仅通过 HTTP 调接口；n8n 加 Basic Auth（见 §9）。
