## 2. prototype/v2/ —— 前端原型（保留，新栈继续用）

```
prototype/v2/
├── index.html            外壳 + 全局弹层 + ?v= 版本号（改 JS/CSS 后 bump）
└── assets/
    ├── js/api.js         API 客户端层（token 存取 + fetch/SSE 封装 + 401 跳登录）
    ├── js/app.js         路由 + 页面模板 + ⌘K 面板 + 全部事件委托
    ├── js/data.js        演示数据（金额单位：分）
    ├── js/icons.js       data-ic 图标注入
    ├── css/main.css      全部样式
    ├── icons/            SVG 源文件 + build-icons.js
    └── fonts/            本地字体（Manrope woff2）
```

本地预览：`prototype/` 起静态服务（`python -m http.server 4311`）→ `http://localhost:4311/v2/`。

> 注意：原型里部分页面（对话/记账）曾联调旧后端 API，旧后端已删，这些联调会失效；纯演示数据页面不受影响。新栈接口出来后按白皮书重新联调。
