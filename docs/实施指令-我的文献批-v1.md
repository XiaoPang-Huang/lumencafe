## 任务分解（工程师按序实施，一个 commit 或两个均可，回报注明）

### A. 数据与用户隔离（P23）
1. Alembic 0011（只增）：新表 `paper_library`（id / user_id / paper_id / added_via[crawl|import] / created_at，unique(user_id,paper_id)）；papers 加列 `origin`(varchar: crawl|import, server_default crawl) / `owner_id`(int 可空 FK users)。
2. 可见范围改造（P23 是产品级变更，勿漏）：论文页「全部论文/digest/每日」列表接口与 digest 全部按**本人归属**过滤——本人归属 = paper_users 含本人 ∪ paper_library 含本人 ∪ owner_id=本人。抓取归属逻辑沿用现有打标归属写入（crawl 时已写 paper_users）。「今日推送」本就按个人订阅词打标归属，照此口径统一并回报确认。
3. 删除语义统一：任何界面的删除 = 删 paper_users 本人行 + paper_library 本人行 + **本人批注（paper_notes 该用户该文）**；owner_id=本人且 origin=import 的文献（P22）才级联删 papers 行+COS 产物（pdfs/parsed 全目录）+全文笔记；抓取文献 papers 行不动。7 天清理连带规则不变（只清无 paper_users 归属的——补一条：有 paper_library 归属的也不清）。

### B. 我的文献工作区（P22/P25）
4. `POST /papers/library` {paper_id} 添加（幂等）；`DELETE /papers/library/{paper_id}` 按上述语义删除（返回 {deleted_paper: bool}）；`GET /papers/library` 我的文献列表（含 parse_status/annotations_count/source/origin 排序 created_at desc）。
5. **导入接口**：`POST /papers/import` multipart PDF 上传（限 30MB，校验魔数）→ 建 papers 行（origin=import, owner=本人, title=文件名去后缀）→ 存 COS → 触发解析状态机；`POST /papers/import-by-id` {arxiv_id 或 doi} → 元数据（arXiv API/Crossref）→ 下载（失败明确报错，前端红字通知）→ 建行 → 解析。两者都返回 {paper_id, parse_status}；导入即自动加入 library。papers.url 落原文链接。
6. **前端**：左导航「我的笔记」→「我的文献」（icon 换 book）；页面三段：左列表（搜索框+排序+解析状态点+「导入」主按钮：下拉「上传 PDF / arXiv·DOI 粘贴」）｜中阅读器｜右批注栏（复用现有阅读器全部交互）。详情面板与卡片操作行加「＋ 我的文献」按钮（已加入=「✓ 已在库」，点击=确认删除弹窗）。详情面板笔记区改纯只读卡+引导行「到我的文献中阅读与批注」；详情「已解析 ✓」点击改跳我的文献并打开该篇。
7. **删除确认弹窗**：红字原句「删除后该文献及其相关笔记会一并删除，且不可恢复」，按钮「确认删除」（danger 红）；抓取来源的文献文案变体「将移出我的文献并删除你对它的笔记」。

### C. 对照翻译（P24）
8. `POST /papers/{id}/translate` → 读 content_list → 过滤 text 类块 → 分批（每批≤20 块）走网关 chat_once（app_key=papers_config，系统提示词：学术翻译忠实直译、保留术语原文括注）→ 组装 {block_id: 译文} 存 `parsed/{id}/translation.json`（storage 抽象）；状态记 papers 新列 translate_status(none|running|done|failed)/translate_error（0011 一并加）；`GET /papers/{id}/translate-status`。幂等：done 直返；缓存已存块跳过（断点续译）。超时/失败可重试。
9. 阅读器：工具条加「对照翻译」按钮（未译=触发，running=轮询，done=逐段对照视图：段落下展开译文行（建议段落内嵌灰字译文行，比左右分栏窄屏友好），再点收起；failed=红字+重试。
