# 05 · 视觉设计风格

## 1. 总体视觉语言

RAGFlow 新视觉体系是**「shadcn 语义 token + 黑白灰中性色 + 青绿点缀」**的极简工具风：近黑主按钮、白底卡片浅灰页面、细边框、小圆角、Inter 字体、lucide 细线图标。整体观感接近 Linear / Vercel 系，强调信息密度与克制的品牌色露出。

## 2. 配色方案

### 2.1 设计 token 定义（证据：`web/tailwind.css` `:root` / `.dark`、`web/tailwind.config.js`）

亮色模式核心值：

| Token | 值 | 用途 |
|---|---|---|
| `--bg-base` | `#ffffff` | 页面底 |
| `--bg-canvas` / `--bg-list` | `246 246 247`（#F6F6F7） | 画布/列表底 |
| `--bg-title` | `#f6f6f7` | 标题栏 |
| `--bg-card` | `rgba(0,0,0,0.05)` | 卡片底/分隔（5% 黑） |
| `--bg-component` | `#ffffff` | 组件底 |
| `--bg-input` | `rgba(0,0,0,0.05)` | 输入区底 |
| `--text-primary` | `22 22 24`（#161618） | 主文字/主按钮底 |
| `--text-secondary` | `117 120 122` | 次要文字 |
| `--text-disabled` | `#b2b5b7` | 禁用 |
| `--border-default` | `rgba(0,0,0,0.2)` | 默认边框 |
| `--border-button` | `rgba(0,0,0,0.1)` | 按钮/弱边框 |
| `--accent-primary` | `0 190 180`（**#00BEB4 青绿**） | 强调：accent 按钮底、底边条、思维链 |
| `--state-success` | `59 160 92` | 成功 |
| `--state-warning` | `250 173 20` | 警告 |
| `--state-error` | `216 73 75` | 错误/删除 |
| `--metallic` | `#46464a` | 金属渐变中间色 |

辅助语义色：知识图谱分类色板 11 色（`--graph-node-1..10 + other`）；团队角色色（group #5AB77E / member #5C96C8 / department #8866D3）。

**品牌渐变**：`#40EBE3 → #4A51FF`（首页 Banner 大字）；历史主色 `#338AFF`（`theme/vars.less` 遗留，旧 Ant 体系）与 `button-blue-text #1677FF` 仍有少量残留。

### 2.2 关键洞察

- **主按钮是近黑色**（`bg-text-primary #161618`），不是品牌色——品牌青绿只出现在 `accent` 变体、按钮底边条（`border-b-accent-primary`）、登录页光晕等点缀位。
- 深色模式是同一 token 的对称反转：`--bg-base #161618`、`text-primary` 变成 `#F6F6F7`（`--*-inverse` 变量互为镜像），两套主题只维护一份结构。
- 语义色带 5% 浅底变体（`accent-primary-5`、`state-error-5` 等，Tailwind alpha 修饰），用于 hover/选中底。

## 3. 字体

证据：`web/src/global.less`、`web/src/inter.less`

- 全局 **Inter**（本地 woff2，全字重 Thin→Black + Italic，约 18 个文件），支持可变字体时升级 `InterVariable`（`font-optical-sizing: auto`）。
- 字号阶梯走 Tailwind 默认（h1 `text-2xl bold` / h2 `text-xl semibold` / h3 `text-lg medium` / h4 `text-base normal`）。
- 基础字号 14px（`text-sm` 按钮），大标题用 44px+ 自定义（首页 Banner）。
- `font-feature-settings: 'rlig' 1, 'calt' 1`。

## 4. 圆角与间距

证据：`web/tailwind.config.js` borderRadius、各组件 className

- 圆角阶梯（自定义，比 Tailwind 默认略小）：`xs 4px / sm 5px / default 6px / lg 7px / xl 8px / 2xl 10px / 3xl 12px / 4xl 16px`，另有 `px 1px`、`2xs 3px` 微调位。按钮默认 6px，卡片 8-12px，输入框胶囊 28px（对话输入 `rounded-[28px]`）。
- 边框默认 **0.5px**（自定义 `borderWidth 0.5`）——细边框是质感来源之一。
- 按钮尺寸：xl 48 / lg 40 / default 32 / sm 28 / xs 24（高）；配套 icon 尺寸方按钮 12~48。
- 列表页外边距：`px-5 pt-8`，卡片网格 `gap-6`，侧栏折叠 64px / 展开 240px，会话侧栏 296px，详情页次级侧栏 64/200px。
- 滚动条：全局细滚动条（`scrollbar-width: thin`，thumb 用 `--border-default`），悬浮才显形（`.scrollbar-auto` hover 出现 30% 黑 thumb）。

## 5. 组件样式

### 5.1 按钮体系（证据：`web/src/components/ui/button.tsx`）

cva 变体分三个系列，约 15 个变体：

| 系列 | 变体 | 形态 |
|---|---|---|
| Solid | default | 近黑底白字（`bg-text-primary`） |
| | secondary | 5% 灰底 |
| | highlighted | 黑底 + 青绿底边条 |
| | accent | **青绿底白字**（品牌强调位） |
| | destructive | 红底白字 |
| | metallic | 黑底 + 青绿/蓝底边渐变（登录页主按钮） |
| Outline | outline / dashed / transparent / danger（红描边） / danger-hover（hover 变红） | 灰底弱边框 |
| Ghost | ghost / delete（hover 变红） / link / static | 透明底 |

尺寸 xl/lg/default/sm/xs + icon 方形系列；内建 `loading`（旋转 Loader2）、`dot`（右上角红点）、`block` 撑满。

### 5.2 反馈组件

- **Toast**：sonner 封装，顶部居中 2.5s（`components/ui/message.ts`）。
- **确认删除**：`ConfirmDeleteDialog`（Radix AlertDialog，红色删除键）+ 命令式 `Modal.show` 两种并存。
- **复制反馈**：图标变绿勾 2 秒 + Tooltip。
- **加载**：路由级为毛玻璃遮罩 + 旋转环（`backdrop-blur-[1px]`，`routes.tsx` L94-97）；行内为旋转细环。

### 5.3 图标

统一 **lucide-react**，常规 `size-4`（16px），按钮内 svg 自动约束 `size-4`；自定义业务图标走 `data-ic` 风格的内置 SVG 组件（`components/icons`）+ 品牌 logo SVG。

### 5.4 动效（证据：`web/tailwind.config.js` keyframes）

- 交互过渡统一 `transition-colors`（快速、克制）。
- 预置 keyframes：accordion 开合 0.2s ease-out、caret-blink 光标闪烁、spin-reverse、bell-shake 铃铛摇动（通知）。
- 登录卡片 3D 翻面（`rotate-y-180` + backface-visibility 探测降级）。
- 页面级过渡：`animate-fade-in-down/up`（搜索页三态切换）。
- 列表页懒加载路由：`Suspense` + 毛玻璃 fallback。

## 6. 版式模式速查

| 场景 | 规格 |
|---|---|
| 列表页标题 | `mb-4 px-5 pt-8` + icon + 标题 + 筛选/搜索/主按钮同行 |
| 卡片网格 | `grid gap-6 sm:1 md:2 lg:3 xl:4 2xl:5 content-start` |
| 空态卡 | 480px 虚线边框 + 居中 24px Plus，可点击 |
| 对话输入框 | 胶囊 `rounded-[28px]`，内嵌附件 chip + 圆形发送键 |
| 消息气泡 | 无气泡边框，纯文本 + 头像分区（assistant 左 / user 右），hover 显操作条 |
| 代码块 | SyntaxHighlighter 高亮，块内滚动 |
| 思维链 | `<details>` 折叠块，青绿色系 |
| 引用 | 行内上标标记 + HoverCard 悬浮原文 + 点击进 PDF 定位 |
