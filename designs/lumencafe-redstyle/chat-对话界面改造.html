解释一下什么是向量数据库
DeepSeek V4.1 Flash已完成 · 12.8s

向量数据库是把文本、图片等转成向量（一串数字）后按相似度检索的数据库。和传统数据库按「精确匹配」查不同，它按「意思接近」查。

对比项传统数据库向量数据库
查询方式精确匹配（WHERE）相似度匹配（KNN）
典型用途订单、账号语义搜索、RAG
代表PostgreSQLpgvector / Milvus

我们的论文库就是「PG + pgvector」方案，用 embedding 把段落向量化后存同一张库。

CREATE INDEX ON papers USING hnsw (embedding vector_cosine_ops);
一句话：传统数据库找「等于」，向量数据库找「像」。
